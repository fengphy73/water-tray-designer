# 出水口接水收納架設計器 v1.1

給熱水瓶出水口用的靜態網頁。調整寬高深與間隙，預覽組裝後的樣子，並下載可切片的 STL。

公開網址：<https://fengphy73.github.io/water-tray-designer/>

## 開啟 GitHub Pages

這是沒有建置步驟的靜態網站，從倉庫根目錄提供 `index.html`。

1. 打開這個倉庫的 **Settings**。
2. 左側選 **Pages**。
3. Source 選 **Deploy from a branch**。
4. Branch 選 **main**，資料夾選 **/ (root)**。
5. 儲存後等網站更新，再打開上面的網址。

## 本機預覽

ES module 需要網站伺服器，不能直接用檔案總管點開：

```bash
python3 -m http.server 8765
```

然後打開 <http://127.0.0.1:8765/> 。three.js 與 OrbitControls 已放在 `vendor/`，沒有網路也能轉 3D 預覽。

## 這座架子

放在檯面上、出水口正下方。熱水瓶本身不墊高。象印 CV-DHF50 這類機器大約 22 寬 × 28 深 × 40 高 cm。杯子坐在格柵蓋上，水滴穿過平行槽，落入可抽出的集水盒；下面是收納抽屜。兩件都從前方拉出。倒水時不必掀開格柵蓋。

外殼外側四條直立外角可做圓角（參數「外殼圓角半徑」，預設 5 mm）。其他邊維持直角；內腔、集水盒與抽屜的外形與滑動配合不變。半徑若大於壁厚可容許的值，會自動縮小為「壁厚 − 1 mm」，以免切到內腔或讓側壁前緣過薄。因此預設壁厚 3 mm 時，實際圓角是 2 mm。設為 0 即回復直角。格柵槽寬建議 3 mm（也是預設值），較 2 mm 不容易卡住茶垢。

四個 STL 都是單一封閉殼，單位 mm：

| 檔案 | 零件 | 列印方向 |
|---|---|---|
| `shell.stl` | 外殼：底板、左右壁、後壁、開放正面；有抽屜時中間有隔板；頂部左、右、後有凸緣，格柵蓋放上去後與外殼頂齊平 | 背面貼床，開口朝上 |
| `grille.stl` | 格柵蓋，前後方向的排水槽 | 平放 |
| `catch-box.stl` | 集水盒，前方指扣（底面向下斜 45°，方便不加支撐） | 底面貼床 |
| `drawer.stl` | 收納抽屜，前方指扣 | 底面貼床 |

預覽畫的是即將下載的同一份網格。畫面上的組裝位置與「分解」位移只存在於預覽，不會寫進 STL。

## 怎麼用

1. 量出水口底部到檯面的距離。
2. 杯子放在格柵上。總高度 H 要讓杯口比出水口低 2–3 cm。粗估：H ≈ 出水口離檯面 − 杯高 − 20～30 mm。預設 H = 100 mm。
3. 拖曳旋轉、滾輪縮放。可分別開關外殼、格柵蓋、集水盒、抽屜，或按「分解視圖」。
4. 「下載…」會存該件 STL。「儲存參數／載入參數」使用 `water-tray-parameters.json`。

抽屜內部高度低於 25 mm 時，會自動拿掉抽屜和它的隔間，並在畫面上說明。以其他參數維持預設來算，大約總高度要到 68 mm 才留得下抽屜。H = 60 是沒有抽屜的例子。

某一件的佔床尺寸超過列印平台（預設 250 × 250 mm，可改）時，預覽上方會標示。平台上轉 90° 放得下時，會另外註明。

## 預設配合（mm）

滑動間隙每側 0.4。集水盒與抽屜的寬、深、高都是隔間減去兩側間隙。格柵蓋比凸緣之間的開口大，放進頂部凹槽後每側大約壓住 3.6 mm。外殼圓角只出現在外側四條直立外角，不影響這組配合尺寸。

| 項目 | 預設 |
|---|---|
| 外殼外形 | 160 × 140 × 100（圓角後包圍盒不變） |
| 外殼圓角 | 輸入 5，實際 R = 2（壁厚 3 mm 時的上限） |
| 外殼列印佔床 | 160 × 100，列印高度 140 |
| 集水隔間 | 154 × 137 × 28.8 |
| 集水盒外形 | 153.2 × 136.2 × 28 |
| 集水盒內部 | 147.2 × 130.2 × 25，約 479 mL |
| 抽屜隔間 | 154 × 137 × 61.2 |
| 抽屜外形 | 153.2 × 136.2 × 60.4 |
| 抽屜內部 | 147.2 × 130.2 × 57.4 |
| 格柵蓋 | 153.2 × 136.6 × 4，23 條槽 |
| 凸緣開口 | 146 × 133 |

指扣在盒深之外，往前伸出 9 mm，所以集水盒與抽屜的列印深度是 145.2 mm。

## 檢查封閉實體

需要 Node.js 18 以上，不必安裝套件：

```bash
node scripts/check-outputs.mjs
```

腳本用五組參數產生 STL（寫到 `tmp-output/`，不納入版本庫）：

- 預設（有抽屜，外殼帶圓角）
- H = 60（沒有抽屜）
- H = 200（有抽屜）
- 預設但圓角為 0（直角，用來對照其他零件是否不變）
- 一組列印尺寸範例（H 150、W 150、D 130、集水深度 20、槽寬 3、圓角輸入 5）

每一件會檢查：

- 沒有開放邊、沒有非流形邊、只有一個連通殼、體積為正，並且最低點貼在列印床上
- 外框尺寸與網格包圍盒一致
- 集水盒與抽屜外形 = 隔間減去兩倍單側間隙（沒有抽屜時，集水盒高度維持盛水深度，只確認放得進較高的空腔）
- 格柵蓋放得進凸緣凹槽，又蓋得住開口
- 外殼圓角只改外殼：格柵蓋、集水盒、抽屜與直角版本完全一致；圓角處剩餘壁厚等於壁厚減實際半徑，且不小於 1 mm
